# CodeWide brand concepts

Three provisional, vector-first directions for the CodeWide identity:

- `Foldline` — recommended: a continuous W that combines phone edges, a Fold hinge and an expanded workspace.
- `Relay` — a narrow device and a wider remote workspace joined by one bridge.
- `Wideframe` — an open viewport with a broad central work horizon.

Open [`index.html`](./index.html) for light/dark lockups, Android adaptive-mask previews, monochrome glyphs, favicon/README use, size checks and risks.

## Status

The repository currently has no `DESIGN.md`. These files are concept-selection material, not durable design law or production-ready trademark-cleared assets. Final wordmark outlines, optical correction, color adoption, trademark search and device screenshots belong after direction approval.

## Source SVGs

- [`mark-foldline.svg`](./mark-foldline.svg)
- [`mark-relay.svg`](./mark-relay.svg)

All three marks use a `64 × 64` viewBox and a single monochrome contour so they can be translated to Android VectorDrawable and a themed `monochrome` layer without visual drift.
