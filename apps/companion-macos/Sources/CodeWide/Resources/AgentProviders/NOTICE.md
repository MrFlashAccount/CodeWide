# Agent provider marks

- `AgentProviderCodex.svg` and `AgentProviderClaude.svg` are the same
  monochrome vector marks used by the Android `ProviderIcon` component.
- OpenAI owns the OpenAI mark and Anthropic owns the Claude mark. CodeWide
  renders them as theme-tinted templates only to identify an agent provider.

These marks are not part of CodeWide's own branding and do not imply
endorsement by OpenAI or Anthropic.
