# V1 composer

M5 is implemented. `ComposerFeature` composes the resident editor, context strip, queue edit bar, attachment tray and actions. `ComposerEditor`, `ComposerMicrophone` and `ComposerSubmitAction` preserve native element placement and the mounted editor across draft selection. `ComposerMenu` owns controls/skills intents; route-owned `ComposerControlRoute`, `ComposerActionRoutes`, and `ComposerRuntimeRoutes` present the retained tool activation.

`draft.ts` selects the shared lower seed, reads existing ThreadUiState, owns editor/selection/latest-value refs and persists changes. `settings.ts` owns local preferences, control requests and activation-qualified rollback. `submission.ts` owns one-shot delivery choice and failed pre-admission recovery. `queueEdit.ts` keeps queue editing and uploads in their distinct scope. `attachments/attachmentAdmission.ts`, `attachmentRemoval.ts`, `largePaste.ts` and `reviewAdmission.ts` own draft admission, removal, paste conversion and review acknowledgement. `suggestions.ts` owns skill insertion and selection. `voice.ts` binds the existing retained VoiceInputController; it does not acquire a second recording runtime or dispose JS on feature unmount.

Escaping callbacks use useEvent. Delayed operations capture ordinary activation-owned draft/preferences/upload/send callbacks before awaiting or binding: they must not resolve a new chat through a latest-value callback on settlement. Recovery preserves newer typing, restores a departed chat durably and respects a same-scope replacement owner. Final voice text is supplied explicitly. Drawing and review capture the same draft admission capability before asynchronous work.

Canonical ThreadUiState, ComposerUploads, FileTransferController, VoiceInputController and workspace resources remain lower authorities. Tool pages and tool context chips enter through display slots and public intents. No new protocol, state machine, database, runtime disposal or optimistic entity is introduced.

Validation: M5 V1 gate passed native/web/compatibility typing and lint, 2286 modules/8194 dependencies. Focused composer/upload/voice/queue contracts: 103 passing tests; updated native integration contracts: 21 passing tests. Seven render suites passed 35 tests; the extended native editor suite passed 11 tests including the new retained-editor assertion (36 unique tests across that combined scope). Android and web Expo exports completed. Actual device microphone, gestures, keyboard, background/foreground and performance parity remain unverified under the resolved no-device stop. M6–M8 source ownership is now closed; see the canonical ledger for final evidence.

M7 capability closure: `workspaceCapabilities.ts` exposes only this owner's qualified operations. Private `workspaceAdapter.ts` binds existing lower model/session authority through exact workspace composition; it does not own shared in-flight maps, runtime construction or global cleanup. The broad RemoteWorkspace facade is deleted.
